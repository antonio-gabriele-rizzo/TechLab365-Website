Microsoft Intune Administration

Microsoft Intune • Endpoint Management • Android Enterprise

Portfolio Overview

This portfolio documents a hands-on Microsoft Intune Administration laboratory developed within a Microsoft cloud environment using Microsoft Intune, Microsoft Entra ID and a physical Android Enterprise device.

The project demonstrates the complete lifecycle of Android Enterprise device management, from creating and configuring the Intune laboratory through device enrolment, application deployment, compliance management, configuration profiles, device administration, monitoring and troubleshooting.

Rather than simply describing Microsoft Intune features, the project documents practical administrative activities performed while building a working Intune environment. The technical documentation combines explanations with annotated screenshots and reflects the day-to-day responsibilities of an Endpoint Administrator.

Portfolio Areas

  • Microsoft Intune administration and endpoint management
  • Microsoft Entra ID users and Security Groups
  • Android Enterprise device enrolment using BYOD Work Profile
  • Managed Google Play application deployment
  • Compliance Policy administration
  • Configuration Profile deployment
  • Device management, monitoring and reporting
  • Microsoft Intune troubleshooting and operational support
