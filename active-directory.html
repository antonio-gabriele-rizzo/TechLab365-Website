Windows Server & Active Directory Administration

Windows Server • Active Directory • Windows Infrastructure

Portfolio Overview

This portfolio documents a hands-on Windows Server and Active Directory Administration laboratory developed from scratch within a virtualised environment using Oracle VirtualBox, Windows Server and Windows 11.

The project begins with the preparation of the virtual laboratory and progresses through Windows Server and Windows 11 installation, Active Directory Domain Services, domain administration and the core Windows Server services required to operate an enterprise network.

The repository is the next stage of the TechLab365 learning journey, extending the Microsoft cloud administration work into traditional Windows infrastructure and demonstrating how on-premises identity services complement modern Microsoft cloud technologies.

Portfolio Areas

  • Oracle VirtualBox virtual laboratory deployment
  • Windows Server 2022 installation and configuration
  • Windows 11 client installation and domain integration
  • Active Directory Domain Services and domain administration
  • User, group and Organisational Unit management
  • Group Policy administration
  • DNS and DHCP administration
  • File Server and NTFS permissions
  • Windows Server and Active Directory troubleshooting
