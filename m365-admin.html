Microsoft 365 Administration

Microsoft 365 • Tenant Administration • Cloud Technologies

Portfolio Overview

This portfolio documents a hands-on Microsoft 365 Administration laboratory developed within a dedicated Microsoft 365 Business Basic tenant. The project provides practical experience with the day-to-day responsibilities of a Microsoft 365 Administrator.

The work covers tenant configuration, identity and user management, licence administration, Microsoft 365 Groups, Exchange Online, SharePoint Online, Microsoft Teams, security administration and Microsoft Graph PowerShell automation.

Rather than simply describing Microsoft 365 features, the project documents practical configuration activities carried out within a working tenant, supported by detailed explanations and annotated screenshots in the associated technical documentation.

Portfolio Areas

  • Microsoft 365 tenant administration and configuration
  • User lifecycle and licence administration
  • Microsoft 365 Groups and collaboration resources
  • Exchange Online administration
  • SharePoint Online sites, document libraries and permissions
  • Microsoft Teams administration and collaboration
  • Microsoft 365 security and Microsoft Defender
  • Microsoft Graph PowerShell and administrative automation
