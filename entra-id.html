Portfolio Overview

This portfolio documents my hands-on learning journey in Microsoft Entra ID administration using the same Microsoft 365 tenant developed throughout the TechLab Microsoft 365 Portfolio.

The project focuses on practical cloud identity management, including user and group administration, delegated administrative roles, Multi-Factor Authentication, password management, monitoring, audit logs and identity troubleshooting.

Each documented section combines step-by-step procedures, screenshots, technical explanations and practical examples to provide a reusable Microsoft Entra ID administration reference and demonstrate real-world identity management tasks.

Portfolio Areas

  • Microsoft Entra ID fundamentals and cloud identity management
  • User lifecycle and account administration
  • Security Groups and Microsoft 365 Groups
  • Administrative roles, RBAC and delegated administration
  • Multi-Factor Authentication and authentication methods
  • Password management and account recovery
  • Sign-in and audit log monitoring
  • Microsoft Graph PowerShell administration
  • Identity troubleshooting and investigation
